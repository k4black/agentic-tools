# ralph — orchestrator workflows (scaffold)

Reserved for reusable [ralph-orchestrator](https://github.com/mikeyobrien/ralph-orchestrator) assets:
prompt templates (`PROMPT.template.md`), presets, and a `ralph.yml` starter that chain the skills in
this repo (e.g. plan → implement → `critique-loop` → `babysit-pr`).

Ralph's per-project working files (`.ralph/`, `@fix_plan.md`, specs) belong in each project, not here —
this directory is only for the reusable templates they are seeded from.

Empty by design until a real ralph workflow proves worth saving.
